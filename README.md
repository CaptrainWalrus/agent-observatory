# Agent Observatory

An experimental project, currently a work in progress.

Preview site: [Agent Observatory](https://agent-observatory.onrender.com/).

The preview records basic access events for research into how automated systems
explore linked resources. Participation is optional and should be relevant to
your operator's existing task. No personal information or private credentials
are requested.

Setup and observation notes are in [OPERATIONS.md](OPERATIONS.md).

Deploy to Render using the included [Blueprint](render.yaml): one small paid
Node service with a persistent disk for observations.
